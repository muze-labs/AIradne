## Analyze

Project state / prior evaluation that makes this cycle relevant:

The graph-first baseline passes the shared publication behavior contract, but its `ObjectSpace` class still bundles object lookup, relation storage, relation indexing, mutation validation, traversal, and containment projection. The accepted composition design says this does not yet test the full Airadne idea.

Important risk / uncertainty / desired movement:

This cycle should create executable evidence for cleaner abstractions, not simply split a class into files. The implementation must show that graph primitives can be independently understood and tested without publication-domain semantics leaking into the kernel.

Relevant human direction / feedback:

- Human accepted `CYC-20260903-XCTYG-19` and its caveat-adjusted compositional design.
- Extra vocabulary is allowed when it reduces AI context burden and makes semantics more explicit; human learning cost is relevant but not decisive for this AI-first test.
- The project prefers coherent cycles over very small bookkeeping-only cycles.

Governing higher-level plan / direction:

Accepted design `DES-20260903-XCTYG-21` defines the intended primitive boundaries: object registry, relation facts, relation index, graph traversal, containment projection, and publication-domain rules over those primitives.

Current position in that plan:

The methodology and design are accepted. This cycle now implements and evaluates that decomposition.

## Plan

### Cycle Goal

Refactor the graph-first object-space implementation into independently testable graph primitives while preserving the existing publication behavior contract and explanation outputs.

### Commitment Boundary

Proceed with runtime and test changes within the accepted design boundary. Do not add parser syntax, command logs, persistence, generated runtime, UI, or fixture semantic changes.

### Why Now / Why This Cycle Boundary

This is the direct implementation follow-up to the accepted design. It is one coherent causal unit: extract primitives, prove their boundaries with tests, preserve behavior, and record evidence.

### Current Starting Evidence

- `CYC-20260903-XCTYG-19` accepted the abstraction method and compositional object-space design.
- `DES-20260903-XCTYG-21` proposes concrete primitive boundaries and falsification checks.
- `EVD-20260903-XCTYG-17` verifies the current graph-first baseline with 30 passing tests.
- `FBK-20260903-XCTYG-18` says the current `ObjectSpace` is not yet compositional.
- `FBK-20260903-XCTYG-23` caveats that human-first language advice must be reinterpreted for AI-first context.

### Evaluation Basis

The cycle is successful when:

- graph primitives exist with domain-neutral tests;
- publication behavior still passes the shared contract;
- `ObjectSpace` becomes a small facade over primitives or disappears;
- relation indexing and traversal do not contain publication-domain semantics;
- containment projection is separate from generic traversal and explicitly preserves stable ID identity;
- explanation traces remain at least as inspectable as before;
- implementation and verification evidence are recorded.

### Likely Work

- Add `src/graph-primitives.cjs` with object registry, relation facts, relation index, generic traversal, and containment projection helpers.
- Refactor `src/graph-object-space.cjs` to use those primitives.
- Add `test/graph-primitives.test.cjs` with neutral graph tests.
- Run `npm test`.
- Run project-local `.spiral` Turtle parsing.
- Record implementation and evidence artifacts.
- Evaluate for human review.

### Explicit Non-Goals

- Do not add a DSL/parser.
- Do not add persistence or command-log semantics.
- Do not change the publication fixture semantics.
- Do not change the public graph-first publication API unless tests reveal an accepted contradiction.
- Do not claim this is the final Airadne semantic kernel.

### Pause / Re-Plan Conditions

- Primitive tests cannot be written without importing publication semantics.
- The facade remains the main algorithmic center after refactor.
- Explanation output becomes materially worse.
- Existing behavior changes unexpectedly.
